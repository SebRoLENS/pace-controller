# Security and safety policy

## Supported version

Only the latest GitHub release is actively maintained.

## Reporting

For ordinary bugs, open a GitHub issue. For a vulnerability that could expose a computer, network, or instrument to unauthorized control, use GitHub's private vulnerability reporting feature when available rather than publishing exploitation details.

For an urgent physical-pressure hazard, stop using the software, isolate the pressure source according to laboratory procedure, and use the PACE front panel and hardware protections. Software issue tracking is not an emergency channel.

## Scope

PACE Controller is not safety-rated. Its interlocks are supplemental software checks and cannot replace relief valves, rated components, source shutoffs, instrument limits, supervision, or validated laboratory procedures.
